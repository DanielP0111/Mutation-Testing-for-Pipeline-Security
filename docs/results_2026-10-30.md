# First complete benchmark run on git (2026-10-30)

Run: `data/benchmark_full` (20 mutants × 1 run), baseline `data/evaluation/baseline_full`.
Harness: release-style tree (no `.git`), wrap dependencies re-extracted from
`subprojects/packagecache` on every build, `--wrap-mode forcefallback`.
Defenses: `wrap_integrity_check` (static, blocking) and Foreman with a
file-level policy learned from the clean build (dynamic, detecting).

## Findings

1. **Foreman's misses are all "outside its view", none "seen but allowed".**
   Every payload written inside the source tree, and the XZ-style read of a test
   fixture, was detected; the two payloads written to `/tmp` were not. The paired
   in-tree/`/tmp` operators (op_015/op_013, op_016/op_005) isolate this: the
   difference is only where the payload lands.
2. **Meson's package cache acts as a defense against URL redirects.** With the
   wrap re-processed on every build, op_001 and op_012 change `source_url`, but the
   archive named by `source_filename` is already in `packagecache/` and matches
   the pinned `source_hash`, so Meson never contacts the new URL. These mutants are
   live but neutralized (build_valid, no network request).
3. **Removing a dependency's hash usually breaks setup — but for openssl it
   silently removed TLS.** For curl, expat, pcre2 and zlib, Meson stops with
   `Missing key 'source_hash'` (setup_failed). For openssl, which curl uses as an
   *optional* fallback, Meson disables the subproject instead
   (`openssl : NO Missing key 'source_hash' in openssl.wrap`); curl is built with
   `https: auto` instead of `https: openssl`, `libssl.so`/`libcrypto.so` disappear
   from the build outputs, and the git tests still pass. This is a silent
   security downgrade that the oracle currently scores as an unremarkable
   build_valid mutant, because op_002 declares no effect. An effect such as
   "artifact missing vs. baseline" or "feature disabled in the configure summary"
   would capture it.
4. **How the target is built changes the results.** Building from a git checkout
   (with `.git`) made git's version script read every tracked file during compile,
   which hid the XZ-style read from Foreman and stamped every mutant `-dirty`. The
   harness now builds release-style trees.
